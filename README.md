# Pygmy

This is a quick pygame platformer I made across a week for the HackClub milkyway event. It provides some updates to my old level editor (flood fill, eyedrop - yay!) and also has some fancy postprocessing fx (lighting, shockwaves, fog).

## How to run:

If you just want to play the game, you can download it from the github [release](https://github.com/snej55/pygmy/releases/tag/v1.0) or from [itch.io](https://snej55.itch.io/pygmy). I recommend the itch release, as it includes all the gameplay instructions and such.

If you want to set it up yourself:

```
# clone the repo:
git clone https://github.com/snej55/pygmy.git
cd pygmy

# setup virtual environment
python3 -m venv .venv
./.venv/bin/activate # os dependent
./.venv/bin/pip install -U pygame-ce moderngl

# run it!
./.venv/bin/python3 main.py
```

If you encounter any issues, please let me know!
